# b2 후속 조합 실행 판단

사용자가 2026-11-11에 AGENT_PROMPT.md를 읽고 진행하라고 지시했다. 통합 계획의 10조건을 그대로 실행한다. 이전 중단 기록은 보존한다.

전문가는 hidden8 GRU, 16차원 공유 상태와 horizon head를 쓰며 미래값을 직접 예측한다. gate 입력은 관측 변화율·표준편차 4개, 해당 학습 부분에서 fit한 PCA 공간 거리, 현재 인식값의 표준화 크기와 전문가–hold 불일치 8개다. horizon·채널별 출력을 별도로 내므로 총 입력은 14개다. C의 범위는 0.5~1.5 및 −0.1~0.1을 유지한다.

gate·C는 작은 OOF 자료 전체를 한 배치로 고정 100epoch 학습한다. OOF 전문가와 최종 전문가는 각각 고정 20epoch이며 별도 early stopping을 하지 않는다. PCA와 모든 표준화 통계는 각각의 학습 ID에서만 fit하고 영수증에 ID·그룹·transform SHA를 기록한다. 분포 거리는 이 학습 표준화 PCA 공간의 원점으로부터의 RMS 거리다.

최초 10조건과 사전에 정한 추가 seed 규칙만 사용한다. 선택적 후속 조건은 필수가 아니므로 0개로 등록한다. 추가 seed는 내부에서 C08이 C01에 Pareto 개선을 보인 경우에만 두 조건에 대해 실행한다. 외부 정답 파일은 이 실행기의 audit hook이 차단하며, 채점은 선택 lock 이후 별도 프로세스로 수행한다.
