현재값 유지와 전문가의 상충을 줄이기 위해 M·G·C를 결합했지만, 사전 내부 선택 A+C는 test에서 baseline보다 MAE와 CCC가 모두 나빠져 새 조합의 채택 근거가 되지 못했다.
C08 대 C06에서는 gate가 MAE·CCC를 개선했지만 C08 대 C09에서는 MAE가 나빠졌고, C08 대 C07의 MTP 추가는 두 지표를 악화시켰으며 C08 대 C05의 C 추가는 MAE만 개선하고 CCC는 낮춰 세 요소 모두 필요하다는 주장은 성립하지 않는다.
새 조건 중 test MAE가 가장 낮은 C10도 CCC는 baseline보다 낮았으며, 발표에서는 gate의 부분적 완화 효과와 내부·외부 성능 차이를 실패 분석으로 설명하고 기존 평활화의 작은 관측 이득을 확정적 우위로 표현하지 않는다.

사전 내부 선택은 `B2-C04`다. C08이 내부 C01에 Pareto 개선을 보이지 않아 추가 seed는 0개이며 선택적 후속 조건도 0개다. 조건별 전문가를 중복 fit하지 않았고 전문가 실제 fit는 16회다. gate·C는 OOF 예측에서만 학습했다.

네 split 전수 결과와 horizon·V/A·그룹·관측 변화율·OOF 불일치 구간별 진단은 CSV에 남겼다. baseline/기존 GRU와의 점수 차이는 float64 독립 집계와 기존 float32 계산 차이로 최대 7.65e−8이며 같은 입력 예측을 사용했다. 10조건×64사례 예측 재생 차이는 모두 0이다. 단일 seed이며 고정 backbone의 기존 개발 영역 노출과 반복 열람한 평가 자료의 한계가 남는다.
