# Technical Report

## 작업 요약과 선택 이력

과제원문 3.1이 예시한 Motion Prediction 시나리오는 관계 변화, 인물의 감정 변화, 보행자 위치 변화, 이벤트 발생 등 서로 성격이 다른 예측을 포함한다. 처음에는 요구된 다양한 시나리오를 모두 다루려 했으나 하나의 end-to-end 모델로 각 과제의 데이터·평가·실패 분석을 함께 처리하는 것이 수행 기간과 자원 안에서 현실적이지 않다고 판단해 **Agent를 세 개의 forecasting head로 분해**했다(Scene graph · Affect · Trajectory).

각 head는 먼저 **최신 상용 Sol API와 공개 베이스라인 기반 로컬 모델을 같은 사례로 비교**했다. 초기 비교에서 Sol 응답이 세 head 모두에서 큰 우위를 보여, Sol 응답에 작은 보정을 얹는 **API 경로(관계 점수 head · 관측 잔차 Ridge · 등속도 혼합)** 를 각 head의 1차 Ours로 채택했다. Affect head의 Ridge 보정은 학습을 위한 추가 Sol 호출 비용이 과다하여 **과거 확보한 Sol 응답을 Train/Selection/Test 로 분할해 재사용**하는 타협으로 완성했다. 이 분할의 범위와 한계는 2·4장에서 공개한다.

API 경로가 완성된 뒤 **API 비용·호출 승인이 제약이 되는 운영 시나리오**에서도 Agent를 동작시킬 수 있어야 한다는 판단으로, 외부 추론 API 없이 동결 체크포인트만으로 실행하는 **로컬 경로**를 뒤이어 개발했다(9장). 로컬 경로의 설계·학습 루프는 Codex 기반 반복 실험을 활용해 짧은 기간 안에 여러 구조·학습 조건을 비교하며 선정했다. 그 과정에서 공개 데이터셋의 가용 범위에 맞춰 **평가 프로토콜을 로컬 경로에 맞도록 조정**했기 때문에, API 경로의 평가집합(예: final 421·공통 1,939)과 로컬 경로의 평가집합(official_test 438·240,890 장면)은 cutoff·사례 모집단이 서로 다르다. 아래 두 경로의 숫자는 **각 경로 내부의 같은 집합 baseline/Ours 비교로만 해석**하며, 직접 수치 비교로 우열을 주장하지 않는다. 동일 집합 통합 평가는 제출 기한 내 완료하지 못했다.

## 1. 문제 정의와 성공 기준

영상 편집과 장면 분석에서는 현재 프레임의 인식뿐 아니라 다음 순간에 무엇이 바뀔지 확인하는 기능이 필요하다. 이 과제는 Track 1 Motion Prediction Agent로서 사람과 물체의 관계 예측(Scene graph head), 특정 인물의 관찰된 감정 상태 예측(Affect head), 보행자의 이동 예측(Trajectory head)을 다룬다. 공통 목적은 관측 종료 이후의 구조화된 정보를 제공하고, 그 판단을 원영상과 정답에 연결해 검토할 수 있게 하는 것이다. 세 head로 분해한 이유는 (1) 서로 다른 입력·평가 규약을 각자 공식 benchmark 조건에서 검증 가능하게 하기 위해서, (2) 각 head의 개선·악화·실패를 독립적으로 보고하기 위해서, (3) end-to-end 설계에 비해 모듈별 교체·확장이 용이하기 때문이다.

성공 기준은 동일 입력·평가 집합에서 각 경로의 baseline과 비교하고, 개선과 악화를 함께 확인하며, 저장 입력에서 결과를 재현하는 것이다. 모든 지표의 동시 개선이나 범용 영상 서비스 완성을 성공했다고 소급 정의하지 않는다. 2~8절은 API 경로와 공통 시각화·환경을 다루고, 9절은 로컬 경로 실험과 제출 연결을 다룬다.

## 2. 데이터와 프로토콜

| 과제 | 데이터와 구성 | 관측·예측 | 평가 집합과 주의점 |
|---|---|---|---|
| 관계 예측 | Action Genome의 Charades 영상·객체·관계 주석 | 관측비율별 입력, 주표는 50%; 나머지 annotation 시점의 관계 | 주표 PGAGS 1,737 / GAGS 1,750; 전체 일정 13,948 중 유효 13,635, 빈 미래 313 |
| 감정 상태 예측 | VEATIC 124개 대상 영상의 관측·평정, 자체 forecasting 구간 | 관측창 8초, 실제 요청 프레임은 manifest에 기록; 미래 +0.5/+1/+2/+3초 | 1,258요청, 908유효; 내부 train251 / selection236 / final421 |
| 보행 궤적 예측 | TrajNet++ 저자 변환 공개 validation 좌표 | 0.4초 간격 관측 9점, 미래 12점; nominal meter | 요청 1,943, Sol 제공 1,939, 누락 4 |

관계 예측 PGAGS는 관측 GT bbox, GAGS는 관측 GT bbox/class를 제공받는다. 관측50%는 benchmark의 주석 프레임 분할 비율이며 영상 재생시간의 절반을 뜻하지 않는다. 미래 annotation frame schedule과 IoU=0 평가 조건도 알려져 있으므로 순수 영상 서비스와 다르다. 감정 상태 예측은 원본 그룹과 ID 분리, 실제 영상 PTS와 GT 최근접 시각을 사용한다. +0.5초 GT는 25fps에서 +0.48초가 될 수 있다. GT 보간으로 정답을 새로 만들지 않는다. 감정 상태 예측의 8초 관측창 전체 프레임이 API에 전송된다는 뜻은 아니며 실제 선택 프레임은 `data/b2/inputs/forecast.json`을 따른다. 보행 궤적 예측은 영상 좌표 추출·카메라 변환을 제공하지 않는 좌표 benchmark다.

감정 상태 예측 final421과 train251은 표본 ID·원본 그룹 중복이 없지만 기존 평가 풀의 내부 분할이다. 공식 VEATIC 인식 train/test 재현 성적이 아니고, final을 이미 여러 번 확인했다. 관계 예측·보행 궤적 예측의 최종 방법 역시 이미 확인한 평가 성적을 근거로 선택했다. 이 결과를 새로운 hidden test 일반화 성능으로 부르지 않는다.

데이터 원출처와 권리 조건은 [사용 내역](USAGE_AND_SCOPE.md)에 정리했다. Action Genome은 [공식 데이터 안내](https://github.com/JingweiJ/ActionGenome)의 Charades 영상과 주석을 사용한다. VEATIC은 [공식 프로젝트](https://veatic.github.io/)의 연구 목적 배포 데이터이며 원영상 저작권은 원권리자에게 남아 있다. TrajNet++는 [공식 데이터 저장소](https://github.com/vita-epfl/trajnetplusplusdata)의 변환 좌표를 사용한다. 연구용 로컬 확보와 채용 제출·웹 재배포 허가는 같지 않으므로 재배포 가능 범위는 제출 전 확정해야 한다.

## 3. Agent 설계와 구현

[System Architecture](SYSTEM_ARCHITECTURE.md)의 흐름에 따라 관측 자료, 저장 API 응답, 후처리, 평가를 분리한다. 모델 식별자는 기존 요청 기록의 `gpt-6.1-sol`, API는 Responses endpoint다. 현재 실행은 신규 API 호출이 아닌 기존 응답의 무결성 확인과 재생이다. 실제 provider 내부 가중치 버전은 이 식별자만으로 확정할 수 없다.

- **관계 예측:** raw Sol 관계 순위와 관측 특징을 94차원으로 구성해 동결 `macro_direct` 선형 head로 26관계 확률을 만든다. NC/WC마다 다른 모델을 고르는 router는 없다. WC 기준을 통과하지 못한 이력과 NC 기준 사후 선택을 보존한다.
- **감정 상태 예측:** raw Sol 미래 V/A에 현재 Sol V/A, 관측 로컬 V/A와 변화 특징을 이용한 `observation_residual_lambda1` Ridge 보정을 더하고 범위를 [-1, 1]로 제한한다. 기존 동결 모델을 selection236 MAE로 선택했다. 현재 사용한 모델은 과거 모델과 동일하며 새 모델 성과로 중복 집계하지 않는다.
- **보행 궤적 예측:** `0.75 × Sol + 0.25 × CV`로 좌표를 결합한다. CV는 관측 위치의 등속도 외삽이다. 비율은 기존 개발 과정에서 고정된 값을 유지한다.

미래 GT 접근은 예측 단계에서 차단하고, 평가기와 시각화에서만 연다. 감정 상태 예측은 요청·응답 서명·해시·모델·endpoint를 확인한다. 보행 궤적 예측은 raw 응답을 재파싱해 저장 좌표와 대조한다. 캐시 누락은 새로운 API 요청으로 복구하지 않는다. 소스·응답 provenance·동결 가중치는 각각 구분하며 원문 응답을 번역하거나 덮어쓰지 않는다.

## 4. 정량 평가

수치는 기존 확정 결과를 인용한다. 아래 표 전체를 이번 준비 작업에서 새로 수집·학습한 결과로 해석하지 않는다. 관계 예측 R@20은 프레임별 정답 관계 중 상위 20개 예측으로 찾은 비율의 평균이며 mR@20은 관계 종류별 recall의 평균이다. WC는 관계 제약을 적용하고 NC는 적용하지 않는 기존 평가기 설정이다. 둘을 합산하지 않는다.

### 관계 예측 관측 50%

| 방법 | GAGS NC R@20 / mR@20 %↑ | PGAGS NC R@20 / mR@20 %↑ | GAGS WC R@20 / mR@20 %↑ | PGAGS WC R@20 / mR@20 %↑ |
|---|---:|---:|---:|---:|
| baseline raw Sol |47.3739 / 52.8927|40.6693 / 46.5423|43.8103 / 32.1818|35.2692 / 26.3686|
| ours macro_direct |61.7654 / 63.4819|52.2368 / 51.3102|42.1704 / 35.3517|33.7820 / 29.6046|

NC에서 개선되지만 WC의 R@20은 악화한다. 기존 WC 개발 gate의 `accepted=false`를 숨기지 않는다. 근거: `src/api_based/ours/b1/README.md`, `data/b1/selection_audit`, `results/api_based/b1/ours_replay/`.

### 감정 상태 예측 동일 final421

| 방법 | MAE↓ | CCC↑ |
|---|---:|---:|
| baseline raw Sol |0.222684|0.533652|
| ours 관측 잔차 Ridge λ1 |0.191646|0.485849|

MAE는 두 축·네 horizon의 절대오차 평균이다. CCC는 `2cov(y,p)/(var(y)+var(p)+(mean(y)-mean(p))²)`이며 축·horizon별 8개 값의 평균이다. MAE 13.94% 감소와 CCC 악화를 함께 보고한다. selection236에서는 MAE 0.255143→0.197490, CCC 0.536874→0.559004였다. 전체 1,258 중 대상 기권 287·대상 미확정 63을 제외한 908개에서 내부 split을 적용했다. final421 성적을 전체 요청 제공률로 표현하지 않는다. 근거: `docs/API_B2_FINAL.md`, `results/api_based/b2/selection236_final_20261111/`.

### 보행 궤적 예측 공통 1,939

| 방법 | ADE↓ | FDE↓ | Col-II %↓ |
|---|---:|---:|---:|
| baseline raw Sol |0.588297|1.301639|18.875709|
| ours 0.75Sol + 0.25CV |0.571526|1.247040|19.133574|

ADE는 미래 12시점의 2D 유클리드 거리 평균, FDE는 마지막 시점 거리다. Col-II는 예측 대상 궤적과 실제 이웃 궤적 간 충돌을 기존 TrajNet++ 공식 평가기로 계산한다. 단일 예측이며 best-of-20 oracle 지표가 아니다. ADE 2.85%, FDE 4.19% 감소와 충돌률 약 0.258%p 증가가 동시에 나타난다. 근거: `results/api_based/b3/raw_score/scores.json`, `ours_score/scores.json`.

## 5. 정성 검증과 테스트 케이스

각 작업의 같은 사례에 baseline·ours·GT를 표시한다. 지표 차이로 선정한 head별 5개 Demo이며 모집단을 대표하는 무작위 표본이 아니다. 관계 예측은 GT 일치 관계를 연두색으로 표시하고, 감정 상태 예측은 대상 위치와 V/A 오차를, 보행 궤적 예측은 실제 원영상 위의 예측·GT 점을 보여준다. 관측은1x, 미래 구간은0.5x로 재생하고 시간·지표는 원본 기준으로 유지한다. 얼굴 ROI는 표시용 추적이며 보행 점은 저장 예측을 영상 좌표로 투영한 것이다.

보행 궤적 demo는 원영상이 확보된 UCY `students003`·`zara01`의806개 유효 사례에서 5개를 선정했다. 전체 정량 평가1,939개는 바꾸지 않았다. 원 VSP 중심 좌표와 기존 변환기의 스케일을 사용해 `u=x/0.0210+360`, `v=288-y/0.0239`로720×576 영상에 투영한다. 원본25fps에서 frame offset은0이며 선정 5개×21점의 원 주석 대조 최대 축별 오차는0.004998m로 저장 반올림 범위 안이다. 표시 보간은 지표 계산에 사용하지 않는다.

| 테스트 조건 | 선정 이유 | 확인할 결과 |
|---|---|---|
| 관계 예측 변경 | 관계 종류와 시각의 연결 확인 | 공식 평가기의 GT 매칭과 WC에서 잃는 관계를 함께 검토 |
| 감정 상태 예측 동일 인물의 감정 상태 변화 | 감정의 크기와 시간 변화 추적을 분리 | MAE 감소가 실제 변화 추적 개선인지, 평균으로 수축한 것인지 확인 |
| 보행 이동·상호작용 | 거리 오차와 충돌의 상충 확인 | 파란 예측·빨간 GT 위치 및 ADE/FDE/충돌 표시 |
| 누락·모호한 대상 | 잘못된 성공 표시 방지 | 기권/누락을 보존하고 자동 채움·자동 API 호출하지 않음 |

### 최종 선정 15개 사례 요약

각 head 당 5개씩 총 15개의 평균이다. 수치는 `assets/final_demo_manifest.json` 의 `baseline` / `ours` 필드를 head 별로 산술 평균한 것이며, 선정 사례의 평균 개선이지 전체 모집단 성능 아님을 분명히 한다.

| head | 지표 | Baseline 평균 | Ours 평균 | 차이 | 주의할 상충 (4장 모집단) |
|---|---|---:|---:|---|---|
| Scene Graph | NC R@20 (%) | 29.2702 | 89.4042 | **+60.13%p** | WC 조건에서는 4장 집계에서 지표 하락 |
| Affect | MAE | 0.3667 | 0.1680 | **−54.19%** | 전체 final 421 CCC 는 하락 (4장) |
| Trajectory | ADE | 0.3521 | 0.1609 | **−54.30%** | 전체 1,939 ADE −2.85% · 충돌률 +0.26%p (4장) |

사례별 지표는 각 catalog 의 `baseline_metric` · `ours_metric`, 개별 사례 영상은 `demo/data/<head>/videos/` 와 `demo/api_based/<head>/` 의 metadata 에서 확인한다. 선정 평균은 모두 Ours 가 좋은 사례만 뽑은 결과이므로 모집단 집계(4장) 와 분리해 해석한다.

### 실패 사례 분석 (대표 3개 · 모집단 관찰에서 선정)

## 6. 실패 분석과 한계

관계 예측은 관계 빈도를 보정해 NC 점수를 올렸으나 WC 제한에서 유효 관계 선택이 악화했다. NC만으로 전반 개선을 주장할 수 없다. 감정 상태 예측은 크기 오차를 줄였지만 final CCC가 내려가 시간 변화의 상관·분산 구조를 더 잘 재현한다고 볼 수 없다. 보행 궤적 예측은 등속도 혼합으로 평균 위치 오차가 줄었으나 상호작용 회피가 충분하지 않아 충돌률이 높아졌다. 이러한 현상은 집계 결과로 확인한 상충이며, 개별 인과는 추가 대조 없이 단정하지 않는다.

현재 결과에는 이미 본 평가 집합에서의 선택 편향, API 실패에 따른 공통 집합 제한, 관측 주석 의존, 좌표 입력, 새 장비 설치 미검증이 있다. 새 영상 전체 경로와 권리 확인된 시연 데이터 확보가 제출 적합성을 위해 남아 있다. 제출 이후 개선은 독립 평가 split 고정, 관측 전용 검출·추적, 감정 상태 예측 대상 인식 검증, 보행 궤적 예측 충돌 제약을 우선한다.

## 7. 보조 시각화 (제출 범위 외)

제출 외 보조 시각화로 각 head의 예측을 프롬프트화해 NVIDIA Cosmos-Predict2.5 diffusion 모델에 입력하고 생성 영상으로 "예측이 실제 미래 영상에 얼마나 부합하는지"를 정성적으로 확인하는 실험을 수행했다. 생성 결과는 예측 정확도의 정량 지표로 사용하지 않으며 정량 평가(4장)에 포함하지 않는다. 생성 모델이 수치·관계를 그대로 실현한다는 보장이 없고, 기본 후처리의 얼굴 모자이크 등 조건상 제약이 있다. 생성 자산·실험 로그는 제출 저장소 외부(`HWP_CJ4DPLEX_AI_support/submission_cleanup_20261112/cosmos_full/`)에 보존했고 Repository에는 포함하지 않는다.

## 9. 로컬 경로 구현과 평가

API 경로가 세 head 모두에서 완성된 시점에서 **"API 호출 비용·승인이 제약이 되는 운영 시나리오"** 대응을 위해 외부 추론 API 없이 동결 체크포인트만으로 실행하는 로컬 경로를 추가로 설계·학습·평가했다. 이 경로의 설계와 학습 루프는 Codex 기반 반복 실험을 활용해 짧은 기간 안에 여러 구조·학습 조건을 비교하며 선정했다. 실험 중 공개 데이터셋 가용 범위에 맞춰 평가 프로토콜을 로컬 특성에 맞게 조정했고(예: VEATIC Affect의 70/30 영상 분할, Trajectory의 TrajNet++ v4 train 기반 custom 3-fold), 그 결과 2·4장 API 경로의 평가집합과 서로 다른 집합에서 측정된다. 앞 절의 API 모델과 별개이며, 이전 배포의 localpool Ridge·static residual을 최신 방법으로 혼동하지 않는다. 학습은 앞선 실험에서 완료했고 제출 준비에서는 동결 자산을 복사해 추론·평가·시각화를 연결한다.

### 관계 예측: 기준 확률 보정과 학습 메모리

ImparTail ODE의26개 기준 관계 확률 prior를 출발점으로 삼는다. 관측 history4×71을 평탄화한284값, 미래 간격1값, prior26값을 연결한311차원의 선형 head가26개 logit 잔차를 낸다. 잔차에 tanh와 cap을 적용하고 prior logit에 더한 뒤 sigmoid로 확률을 얻는다. 관측 context97차원의 cosine top8 검색은 동일 영상을 제외하며 학습 메모리의 관계 profile을 반환한다. 미래 간격·prior entropy·검색 유사도·prior와 memory 차이의4개 특징으로26개 gate를 계산해 보정 확률과 memory를 혼합한다.

양성 희귀도 가중0.25는 학습 손실 설정이다. 내부 검증에서 R20이 baseline 이상인 후보 중 mR20 최대를 선택해 SGCLS는 cap3 조합, PredCls는 cap1.5 조합으로 고정했다. 선택 lock의 `test_scores_read=false`는 이 선택 실행의 경계이며 전체 연구가 미열람 독립 holdout이라는 뜻은 아니다.

| 관측50%·NC | baseline R20 / mR20 | 최신 Ours R20 / mR20 |
|---|---:|---:|
| SGCLS |0.480268 / 0.336508|0.491097 / 0.418568|
| PredCls |0.633108 / 0.423031|0.666159 / 0.490949|

전체13,635사례와4관측비율×WC/NC를 평가한 기존 기록을 보존한다. 직전 유망 후보와 비교하면 SGCLS R20은8조건 중6조건, PredCls는7조건에서 하락했다. mR20은 각각8조건 모두 상승했다. 원 baseline 대비 성적과 직전 후보 대비 상충을 구분한다. 근거는 `iterative_research_20261111/b1/combinations_81112/RESULTS.md`, `all_settings.csv`, `combined_selection_lock.json`이다.

### 감정 상태 예측: 현재 보정과 미래 변화량 분리

최신 입력은2,740사례이며 train1169·dev265·official_test438·additional868로 구분한다. 전체2,740을 독립 test로 표현하지 않는다. 실제 관측 영상 특징은 마지막1.8초15프레임에서 얻으며,3개 현재 인식값은 각각5프레임의 인식 결과다.8초는 분리·겹침 제거에 사용한 보수적 관측창이다. 얼굴 crop으로 학습한 모델이 아니라 전체 프레임 특징이다.

학습 영역의 두 내부 검증에서 선택한 D04를 사용한다. D02는 마지막 영상 특징과 시간 평균의 PCA16 및 관측 수치6개로 현재 인식 VA의 잔차를 추정한다. D04는 동일 관측 특징에서 미래 GT−현재 GT를 학습한8출력 delta head다. 추론은 D02 보정 현재값에 네 시점 delta를 더한다. PCA·정규화·Ridge는 해당 학습 ID에만 fit했고 내부 선택 뒤 원train1169로 refit했다. ridge0.01 해석적 fit이며 test 결과로 재선택하지 않았다.

주 Baseline은 기존 후속 조합 실험의 C01 GRU 직접 예측 모델이다. 프레임별2048차원 특징의 train-only PCA32와 상대시각1값을 GRU hidden8에 넣고, 마지막 상태8과 관측 수치6을16차원으로 투영한다. 학습된4시점 embedding을 더하고 Tanh·Linear16→2로 각 시점 VA를 예측한다. 같은 train1169에서 MSE로20epoch 학습했으며 MTP·gate·추가 출력 보정을 사용하지 않는다. 원 계산의 C01 고정 혼합은 gate1·scale1·offset0으로 직접 전문가 출력과 같다. 현재 감정 예측 head는 없으므로 현재 MAE/CCC는 해당 없음이다.

사용자가 기존 실험 결과를 확인한 뒤 주 Baseline을 C01로 변경하도록 지정했다. 따라서 이 비교 기준 변경을 test 열람 전 사전 지정이라고 주장하지 않는다. D04의 기존 사전 선택과 동결 가중치는 유지한다. 두 방법은 같은 관측 원자료·split·미래4시점·지표를 사용하지만 특징 투영과 학습 방식은 다르다.

| official_test438 | 미래 MAE↓ | 미래 CCC↑ |
|---|---:|---:|
| Baseline C01 GRU |0.221696|0.565830|
| hold 추가 비교군 |0.220151|0.613004|
| 이전 평활화 참조 |0.219604|0.615501|

D04는 주 Baseline C01 대비 미래 MAE와 CCC가 모두 좋아졌다. 추가 비교군 hold 대비로는 미래 MAE만 낮아지고 CCC는 악화했다. 현재값 MAE도 hold0.216942에서 D04의0.218659로 악화했다. 내부 검증의 이득이 최종 영역의 현재 감정 인식 개선으로 일반화되지 않았다. 기존 GRU의 MAE와 CCC, 평활화의 CCC를 회복하지 못했으므로 모든 학습 모델보다 우수하다고 표현하지 않는다. ### 보행 궤적 예측: 두 상태 반복과 시작 모델 보존

동일3fold 전체240,890장면의 baseline_attention과 최신 D04를 비교한다. 대상 ego 특징·마스킹한 이웃 특징·이웃 mask의125차원을 정규화해128차원으로 인코딩하고, 공유 block으로 y·z 두 상태를 반복 갱신한다.24출력 head의 마지막 결과를12×2 좌표로 변환한다. 추론 입력에는 미래 GT가 없다.

자료는 TrajNet++ v4.0 공개 실사 train을 CFF227,172·UCY11,499·기타 현장2,219로 묶은 사용자 정의 그룹 교차검증이다. 기타 현장은 hotel229·LCAS889·WildTrack1,101장면이다. 세 fold가 각 그룹을 한 번씩 평가하며 공식 challenge test 성적이 아니다. 공개 실사 test3,146장면에는 미래 primary GT가 없어 이 전수 지표에 포함하지 않았다. 원 실험의 `runplan.json`과 `V4_DATA_AUDIT_AND_SPLIT.md`에 분할·기존 공개 자료 노출을 기록했다.

관측9점·미래12점의 시간 간격은 원 scene fps를 따른다. WildTrack1,101장면은0.5초 간격(관측4초·미래6초), 나머지239,789장면은0.4초 간격(관측3.2초·미래4.8초)이다. UCY Demo의0.4초를 전체 데이터의 고정 간격으로 일반화하지 않는다.

D04는 기존 F parent의 optimizer moment/step을 보존하고 lr0.0001·최대10epoch로 추가 학습한 조건이다. 내부 선택에 epoch0을 포함하여 모든 추가 epoch가 나쁘면 시작 모델을 유지한다. 선택 추가 epoch는 fold1=5, fold2=0, fold3=0이다. 이번 제출에서는 최신 추가학습 조건 D04를 명시적으로 연결하며, 전역 사전 선택 winner가 있었다고 주장하지 않는다. 별도 robust epoch 정책과 D04를 하나의 모델로 합치지 않는다.

| 전체240,890장면 | ADE↓ | FDE↓ | 관측 이웃 충돌률%↓ |
|---|---:|---:|---:|
| baseline_attention |1.052211|2.170546|22.046162|
| previous_F 역사적 참조 |1.026588|2.100548|21.200963|
| 최신 D04 |1.058973|2.157528|22.154095|

D04는 baseline 대비 FDE만 낮아지고 ADE와 충돌률은 악화한다. 이전 F의 세 지표를 모두 회복하지 못했다. epoch0 보존의 정상 동작은 최종 성능 개선을 보장하지 않는다. previous_F와 최신 실험은 seed·학습 길이·분할이 함께 달라 역사적 차이를 한 요인의 인과효과로 해석하지 않는다. 관측 이웃 충돌률은 원 scorer의 정의이며 API 평가의 실제 미래 이웃 Col-II와 같은 지표로 합산하지 않는다.

fold1 D04 중복 실행 편차는 원 실험의 quarantine과 복구 receipt에 보존했다. 정상 epoch5 snapshot과 가중치·optimizer·RNG가 동일한 복구 checkpoint를 사용했으며 이 제출 준비에서 재학습하지 않았다. 근거는 `b3/diagnosis_targeted_experiments/RESULTS.md`, `selection_fold*.json`, `execution_deviation.json`이다.

### 로컬 Demo와 재현 범위

각 최신 로컬 baseline/ours를 같은 사례로 비교하고 실제 원영상이 있는 사례에서 5개씩 선정한다. 공개 표기는 Demo이며 실패 영상 분류를 추가하지 않는다. 관계의 공식 GT 매칭은 연두색, 보행 예측은 파랑·GT는 빨강, 미래 구간은0.5x로 표시한다. 감정의 대상이 가려지거나 확인되지 않으면 임의 인물의 얼굴에 결과를 붙이지 않는다. 원영상이 있는 보행 부분집합의 Demo를240,890장면 전체의 대표 표본으로 주장하지 않는다.

| 로컬 테스트 사례 | 같은 사례의 Baseline → Ours | 선정 이유와 확인할 한계 |
|---|---|---|
| 관계 `predcls:GF7DV.mp4_0.5` | NC R20 46.1538% →84.6154% | 공식 GT 일치 관계를 연두색으로 확인. 관계 회수율이며 미래 bbox 추적 성능을 뜻하지 않음 |
| 감정 `v003_official_test_t00139.0400` | C01/D04 MAE 0.373104 →0.103684 | 같은 대상의 미래 VA·오차를 실제 영상과 대조. ROI 추적은 표시용이며 모델 입력이 얼굴 crop이라는 뜻은 아님 |
| 보행 `crowds_students003_4259` | ADE 3.841051 →1.777925, FDE 6.230684 →2.132061, 충돌0→1 | 거리 오차는 줄지만 관측 이웃과의 충돌은 생긴 사례. 위치 오차 감소를 안전성 개선으로 일반화할 수 없음 |

이 세 사례는 정성 설명을 위한 선정 사례이며 전체 성능을 대체하지 않는다. 보행 사례는 동일한 Demo 안에서 거리와 충돌의 상충을 확인하는 실패 분석도 제공한다. 원 수치는 각 로컬 catalog와 동결 예측에 연결돼 있다.

로컬 경로의 입력 경계는 유지한다: 감정은 동결 관측 특징, 보행은 좌표, 관계는 benchmark 관측 객체 정보를 사용한다. 원영상에서 모든 특징을 새로 추출하는 범용 서비스는 아니다. 상세 실행은 각 로컬 branch README를 따른다.
