## 현재 확인된 제출 전 제약

- API 계열은 기존 Sol 응답을 재생한다. 새 영상에서 유료 API를 호출하는 전체 경로를 제공하는 것과 같지 않다.
- 관계 예측은 관측 정답 객체 정보와 미래 annotation frame schedule을 제공받는다. 보행 궤적 예측은 관측 좌표를 입력받는다. 영상만으로 동작하는 일반 서비스 성능으로 표현하지 않는다.
- API 관계·보행은 이미 본 평가 결과를 통한 사후 선택이며 감정 final421도 여러 번 확인한 집합이다. 최신 로컬 관계·감정의 내부 선택 lock과 보행 D04의 명시적 배포 선택을 구분한다. 전체 연구가 독립 hidden test였다고 표현하지 않는다.
- 최신 로컬 보행240,890장면은 v4 실사 train의 사용자 정의 그룹 교차검증이다. 공개 challenge test 성적으로 표기하지 않는다. 감정2,740개 전체도 train·dev·official_test·additional을 합한 수다.
- 권리 확인, 평가자용 외부 리소스 URL, Repository URL·평가 계정 권한은 실제 확보 전까지 완료로 표시하지 않는다.
- ImparTail 보존본의 코드·가중치 이용 허가 범위는 별도 확인이 필요하다. 하위 코드 라이선스를 전체 모델에 자동 적용하지 않으며 상세 미확정 사항은 `docs/RESOURCES.md`를 따른다.
- head별 5개 Demo는 baseline과의 지표 차이를 기준으로 고르는 정성 시연 자료다. 전체 성능과 원문3.4의 실패 분석은 기술 보고서에서 별도로 제시한다.
- Charades 원본 라이선스는 제3자 데이터 배포와 가공본 공개 권한을 부여하지 않는다. 로컬 demo를 그대로 회사에 전달하거나 공개할 수 있다고 가정하지 않는다. 상세 조건과 원문은 `USAGE_AND_SCOPE.md`, `licenses/CHARADES_LICENSE.txt`를 따른다.
- Cosmos 영상은 출력 조건을 이용한 생성 시각화다. 원 예측의 정확도나 실제 미래를 증명하는 결과로 사용하지 않는다.

## 작업 순서

1. API·최신 로컬을 포함한 제출 문서와 실행·환경 안내 작성.
2. 실제 프로토콜 기반 관계 예측·감정 상태 예측·보행 궤적 예측 영상 렌더러 구현.
3. 각 계열에서 같은 사례의 baseline/ours 지표 차이로 head별 5개 Demo 선정.
4. Cosmos 보조 시각화 실험은 수행 후 제출 범위 외로 분리하여 Repository 외부에 보존.
5. 사용자 제공 아키텍처 Figure 3장(overall · API · Local)과 Demo GIF 15개를 README·SYSTEM_ARCHITECTURE에 임베드하여 Repository 열람만으로 결과를 확인하도록 구성.
6. API와 최신 로컬 제출 코드의 필요한 언어 정리·최소 리팩토링 및 검증. 원 실험·기존 모델·결과는 보존.
