Abstract

영상 콘텐츠에서 "곧 무엇이 일어날지"를 알아야 하는 요구는 관계 변화, 감정 변화, 보행자 위치 변화 등 서로 성격이 다른 예측을 포함한다. 본 Agent는 이를 하나의 end-to-end 모델이 아니라 세 개의 forecasting head로 분해해 각각을 benchmark 조건에서 검증한다.

각 head는 먼저 최신 상용 Sol API와 공개 베이스라인 기반 로컬 모델을 같은 사례로 비교했다. 초기 비교에서 Sol 응답이 세 head 모두에서 우위여서 Sol 응답에 작은 보정(관계 점수 head · 관측 잔차 Ridge · 등속도 혼합)을 얹는 API 경로를 각 head의 1차 Ours로 채택했다. API 비용·호출 승인이 제약이 되는 운영 시나리오에서도 Agent를 운영할 수 있어야 한다는 판단으로, 외부 추론 API 없이 동결 체크포인트만으로 실행하는 로컬 경로를 뒤이어 개발했다. 두 경로의 평가집합·cutoff는 서로 다르므로 직접 비교하지 않고 각 경로 내부의 same-set Baseline/Ours 비교로 해석한다.

Agent 전체 구성

관측 프레임을 입력받아 세 head가 병렬 동작한다. Scene graph head는 미래 사람·물체 관계를, Affect head는 미래 Valence/Arousal을, Trajectory head는 미래 2D 좌표를 예측한다. 각 head는 독립적 benchmark 평가 규약에 연결되며 공통 평가기와 원영상 오버레이로 결과를 확인할 수 있다.

Method

API 경로

  • Scene graph: Sol 관계 예측 + 관측 문맥 → Relation score head → 미래 scene graph
  • Affect: Sol 미래 VA + Local recognition 관측 VA → Frozen Ridge 보정
  • Trajectory: Sol 궤적 + Constant velocity → 0.75:0.25 Fixed blend

로컬 경로

  • Scene graph: ImparTail ODE prior + Training memory retrieval → Gate & capped correction
  • Affect: Visual encoder + Affect recognizer → D02 current correction + D04 future delta
  • Trajectory: Motion features + Neighbor mask → Two-state model iterative updates

내부 식별자는 b1=Scene graph, b2=Affect, b3=Trajectory. 폴더·CLI 슬러그는 과거 호환성으로 relations·affect·trajectories를 유지한다.

Results

두 경로의 수치는 평가집합·cutoff가 서로 달라 직접 비교하지 않는다. 각 경로 내부의 same-set Baseline/Ours 비교로만 해석한다.
